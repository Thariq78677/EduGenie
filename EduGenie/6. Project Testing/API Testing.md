# API Testing

The API can be tested using the FastAPI interactive documentation at:

http://127.0.0.1:8000/docs

## Endpoints
- POST /qa
- POST /explain
- POST /quiz
- POST /summarize
- POST /learn/recommendations

## Testing Method
1. Start the FastAPI server.
2. Open the /docs page.
3. Test each endpoint with sample input.
4. Verify response structure and error handling.

## Important Note
Gemini API testing requires a valid `GEMINI_API_KEY` and a working internet connection.
